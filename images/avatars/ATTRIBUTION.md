# 3D account avatars

32 stylized 3D portraits created for Master Store using image generation on 25 October 2026.
24 male characters and 8 friendly robot characters, each on a colored background.
The four local WebP sprite atlases each contain a precisely aligned 4-by-2 grid.
CSS displays the corresponding tile; no external image API is needed at runtime.
Existing avatar-01 through avatar-32 preference IDs are preserved.
These replace the previous Notionists illustrations.
