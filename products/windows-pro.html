Windows 11

الإعدادات ← النظام ← حول، ثم مواصفات Windows. سجّل الاسم كاملًا، مثل Windows 11 Home أو Windows 11 Pro.

Windows 10

الإعدادات ← النظام ← حول، ثم مواصفات Windows. اختار باقة تطابق رقم النظام والنسخة الظاهرة.

Windows 7 / 8 / 8.1

راجع اسم النسخة من معلومات النظام أو نافذة winver قبل الشراء. للمساعدة، ابعت اسم النسخة الظاهر للدعم.

بتجهز Windows 11 لجهازك؟ راجع متطلبات المعالج والذاكرة والتخزين وTPM 2.0 وUEFI مع دعم Secure Boot؛ مطابقة اسم النسخة لا تكفي للتأكد من توافق الجهاز.

Microsoft: معرفة معلومات الجهاز · متطلبات Windows 11

  3. أدخل مفتاح المنتج المكوّن من 25 حرفًا واتبع التعليمات. بعدها راجع حالة التنشيط في نفس الصفحة.

Microsoft: تفعيل Windows · خطوات الإصدارات القديمة

أسئلة قبل شراء مفتاح ويندوز

إزاي أعرف أختار Windows 10 ولا 11؟

لو النظام مثبت بالفعل، اختار نفس رقم Windows ونفس النسخة المكتوبة في معلومات الجهاز. لو هتنتقل إلى Windows 11، راجع توافق الجهاز الأول؛ المفتاح وحده لا يجعل الجهاز متوافقًا.

ينفع أشتري Pro والجهاز عليه Home؟

المفتاح لازم يطابق النسخة المراد تفعيلها. لو ناوي تغيّر من Home إلى Pro، راجع الدعم قبل الدفع لتأكيد مسار الترقية المناسب؛ لا تفترض أن إدخال أي مفتاح سيغيّر النسخة تلقائيًا.

مدى الحياة معناها إيه في العرض؟

التفعيل خاص بالإصدار المشترى كما هو موضح في الباقة، دون تجديد دوري له. لا يعني ذلك ترخيصًا لعدد غير محدود من الأجهزة أو ترقية تلقائية إلى كل أجيال Windows القادمة.

التفعيل يشمل Word وExcel أو Microsoft 365؟

لا. دي باقات لتفعيل نظام Windows. برامج Office واشتراكات Microsoft 365 خدمات منفصلة عن مفتاح ويندوز.

ينفع أنقل المفتاح لجهاز تاني أو أغيّر اللوحة الأم؟

إمكانية النقل وإعادة التفعيل تعتمد على نوع الترخيص وتغيير الجهاز. لو ده مهم لك، أكّد الشروط مع الدعم قبل الشراء؛ نوع الترخيص القابل للنقل لا يُفترض من اسم Home أو Pro وحده.

أعمل إيه لو ظهر خطأ في التفعيل؟

راجع تطابق النسخة، واتصال الإنترنت، وإدخال المفتاح كما وصلك. لو استمر الخطأ، أرسل رقم الطلب وكود الخطأ للدعم لمراجعة التفعيل والضمان.

هل التفعيل يمدد دعم النسخ القديمة؟

لا. تفعيل النظام يختلف عن دورة دعم Microsoft. انتهى الدعم القياسي لـWindows 7 و8 و8.1، وانتهى دعم Windows 10 Home وPro المعتاد في 14 أكتوبر 2025. التفعيل وحده لا يضيف اشتراك تحديثات أمنية ممتدة.

Microsoft: دورة دعم Windows 10 Home وPro
