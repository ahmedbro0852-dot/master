# Storefront review — 10 November 2026

## Changes

- Resetting an empty search now synchronizes the hero and catalog fields and clears suggestion state.
- ArrowUp from an unselected suggestion list selects the last result, matching standard keyboard behavior.
- Suggestions close when focus leaves the search group; moving focus within the group retains them.
- Suggestion matching now normalizes Arabic and Western thousands separators consistently with catalog filtering.
- Updated script versions and added interaction regression coverage to the build.

## Validation

Search normalization and interaction regression tests pass. Assistant shopping, request security, Lovable, guest order capture, and creative-service exclusion checks pass. Production build and public-route verification pass (113 generated sitemap URLs).

Full `npm test` is not green: store-knowledge assertions expect outdated ElevenLabs prices (1250/500 rather than current catalog 1100/450).
