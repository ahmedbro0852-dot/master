# Mobile usability improvements

- Simplified the homepage header to four columns; cart remains reachable in the bottom navigation.
- Raised menu, search-clear, quantity and favorite controls to 44px targets.
- Made section shortcuts horizontally scrollable instead of wrapping into multiple rows.
- Reduced hero spacing and shelf padding on phones.
- Stacked payment methods below 420px and enlarged labels.
- Kept account/checkout text fields at 16px to avoid automatic input zoom.
- Hid fixed navigation, purchase and support overlays while editing text on phones.
- Sized the checkout dialog to the visible viewport and kept it independently scrollable when the keyboard opens.

Validation: complete production build and public-route checks passed, including guest order capture, admin controls, search regressions, and the new viewport/focus regression test. Request-security checks passed. Automated mobile visual testing remains unverified because the local browser runtime is unavailable; the public page was inspected at the cloud browser's default desktop viewport. No real orders were submitted.

## Search follow-up

Added a catalog clear button synchronized with the hero search; labels follow the selected language. Mobile keyboards now show a Search action, and submitting a query dismisses the keyboard before scrolling to results. Composition keystrokes no longer submit prematurely. Regression coverage verifies these behaviors and the complete build passes.
