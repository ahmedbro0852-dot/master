# Shared appearance contrast repair

Pair custom-theme text with matching surfaces instead of hard-coded light surfaces or dark text. Covers product card headers/prices, value section, footer, plan features, safe notes, auth tabs/guest links, tracking, countdowns and assistant. Keep original store logo and fixed dark customer showcase. Assistant uses the selected palette, including warm mode. Theme and assistant stylesheet cache keys updated on public pages and generated SEO templates.

Validation: build, npm test, theme-contrast browser test across six public pages and all five appearances at mobile width; theme menu and assistant dialog included. Contrast checks inspect visible direct text on opaque solid ancestor backgrounds (>=4.5:1), skipping gradient/image backgrounds; they do not constitute a full accessibility certification or verification of private authenticated records. Administration keeps its existing separate appearance.
