# Master Store brand refinement

Rebuilt the existing blue/navy/gold MS monogram as clean SVG geometry, with outlined MASTER / STORE lettering that does not rely on web fonts. Kept the established symbol and colors while improving proportions and readability at header size. The same mark is used for the favicon and assistant avatar; transparent PNG is retained for social metadata and legacy consumers (1170 × 360, reduced from 340789 to 32831 bytes).

Public headers/footers now reference the vector directly with intrinsic dimensions; account, invoice, management and generated category pages use the same asset. Logo/version references are updated for browser caches. Category headers keep a light logo surface in dark mode.

Validation: built static product/category pages, unit/knowledge/SEO tests, existing storefront/cart and invoice browser tests; reviewed 320/390/1440 layouts and dark-theme screenshots. No product, price, order or authentication behavior changed.
