# Nasha AI — MVP

Nasha AI is a unified AI workspace concept that brings chat, image and video generation into one interface.

## Current MVP
- Unified chat interface
- Auto model router UX
- Manual model selection
- Image Studio
- Video Studio
- Model library
- Responsive layout
- Demo chat interactions

## Planned backend
The current branch is a front-end prototype. The next step is to connect server-side provider adapters for supported AI APIs, add authentication, usage metering and a credit system.

## Branch
This prototype lives on `ai-hub-mvp` so the existing Master Store site on `main` remains untouched.
