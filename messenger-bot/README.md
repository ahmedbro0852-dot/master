# مساعد ماسنجر بالذكاء الاصطناعي

نسخة أولى جاهزة للنشر على Cloudflare Workers. لم تُربط بصفحة فعلية بعد.

## الموجود
- تحقق توقيع Meta وWebhook verification.
- ردود نصية باستخدام GPT، وموديل قابل للتعديل في wrangler.jsonc.
- لوحة إدارة عربية على الرابط الرئيسي، محمية بمفتاح إدارة.
- معلومات نشاط قابلة للتعديل، والرد الآلي متوقف افتراضيًا.
- ذاكرة آخر 6 رسائل لكل عميل وحفظ العمل المعلق باستخدام Durable Objects.
- منع تكرار آخر 200 رسالة لكل محادثة وحد يومي عالمي لمحاولات الرد.
- كلمة «موظف» أو وصول مرفق توقف البوت على المحادثة. يراجع الموظف المحادثة في صندوق وارد الصفحة؛ لا يوجد تنبيه موظف منفصل.
- لا توجد مدفوعات أو تسجيل طلبات فعلي أو واتساب في هذه النسخة.

## النشر
يتطلب Node.js 22+ وحساب Cloudflare وMeta Developer وصفحة يملك العميل صلاحية إدارتها.

```bash
npm install
npx wrangler login
```

أضف كل سر بشكل منفصل باستخدام الأوامر التالية؛ أدخل القيمة عند الطلب ولا تضع المفاتيح في GitHub:

```bash
npx wrangler secret put OPENAI_API_KEY
npx wrangler secret put META_APP_SECRET
npx wrangler secret put PAGE_ACCESS_TOKEN
npx wrangler secret put PAGE_ID
npx wrangler secret put VERIFY_TOKEN
npx wrangler secret put ADMIN_TOKEN
npm run deploy
```

استخدم قيمًا عشوائية طويلة ومختلفة لـ VERIFY_TOKEN وADMIN_TOKEN. راجع إصدار Graph API المدعوم في تطبيق Meta واضبط GRAPH_VERSION قبل النشر. إذا كانت واجهة Durable Objects تطلب اختيار خطة، اختر الخطة المجانية إن كانت متاحة؛ لا تُفعّل اشتراكًا مدفوعًا بدون موافقة.

في Meta اضبط رابط Callback على `https://YOUR-WORKER.workers.dev/webhook` وقيمة Verify Token نفسها. اشترك في `messages`، واربط الصفحة بالتطبيق باستخدام إعدادات Messenger. صلاحية `pages_messaging` والمراجعة/الوصول المتقدم ووضع Live حسب متطلبات التطبيق لازمة للتعامل مع العملاء خارج حسابات الاختبار. جهز رابط سياسة خصوصية وتعليمات حذف بيانات تتناسب مع النشاط قبل طلب المراجعة.

افتح رابط Worker الرئيسي، أدخل ADMIN_TOKEN ثم اضغط تحميل الإعدادات. أضف الأسعار والسياسات الصحيحة، فعّل البوت واحفظ. اختبر بحساب له دور على التطبيق قبل فتحه للعملاء.

## اختبار
```bash
npm test
npx wrangler deploy --dry-run
```
الاختبارات المحلية تستخدم بدائل لمخزن Cloudflare وخدمات OpenAI وMeta؛ لا تثبت ربط صفحة حقيقية أو توافر صلاحياتها.

## تشغيل ودعم
- اطلب من العميل كتابة «موظف» لإيقاف البوت. أوقف المحادثة يدويًا من لوحة الإدارة باستخدام PSID قبل أن يرد الموظف؛ الرد اليدوي لا يوقف البوت تلقائيًا.
- عند نفاد الحد اليومي لا يرد البوت، ويجب متابعة صندوق وارد الصفحة يدويًا.
- الحد يحسب محاولات GPT وليس توكنات ولا تكلفة مالية؛ اضبط حد إنفاق عند مزود API أيضًا.
- الردود مقصورة على رسائل واردة عمرها أقل من 23 ساعة. لا يوجد إرسال حملات أو متابعة خارج النافذة.
- عند فشل إرسال Meta أو عدم وضوح نتيجته، تتوقف المحادثة بدل إعادة إرسال قد ينتج عنها تكرار. يوجد سجل حالة أخيرة في التخزين، ولا يوجد مراقبة أو تنبيه تلقائي في هذه النسخة.
- إزالة العمل المعلق قبل الإرسال تقلل التكرار، لكنها قد تفقد ردًا إذا تعطلت العملية وسط التنفيذ؛ لا يوجد ضمان تسليم مرة واحدة.
- يبقى تاريخ المحادثة المختصر في التخزين حتى حذفه؛ وفّر سياسة احتفاظ متفقًا عليها قبل التشغيل التجاري. لا توجد إزالة دورية تلقائية.
- لحذف بيانات عميل: POST إلى `/admin/delete`، Authorization: Bearer ADMIN_TOKEN، وجسم JSON يحتوي sender. الحذف يلغي العمل المعلق أيضًا.
- لوحة الإدارة لا تخزن مفتاح الإدارة في المتصفح. لا ترسل المفاتيح في الدردشة ولا تضعها في ملفات منشورة.
- هذه النسخة تستخدم نقطة OpenAI الرسمية. المفاتيح من وسيط لا تعمل بالضرورة ويجب تعديل الاتصال بعد التحقق من مزوده.

## التكلفة
استهلاك GPT مدفوع. Workers وDurable Objects ضمن حدود الخطة المجانية المتاحة في حسابك؛ ليست هناك ضمانة تشغيل بلا حدود أو SLA في الخطة المجانية. راجع الحساب قبل نشر خدمة لعميل.
